# SDD Demo: To-Do App

A live walkthrough of **Spec-Driven Development (SDD)** using Claude Code.

## Goal

Build a simple to-do app with **Vite + React**, following the full SDD workflow:

1. **Explore** — Think through the problem, clarify requirements, and investigate constraints before writing any code.
2. **Propose** — Generate a complete change proposal: design, specs, and implementation tasks in one step.
3. **Review** — Inspect the generated spec and tasks together before committing to implementation.
4. **Apply** — Implement the tasks from the spec, one by one, with Claude Code doing the heavy lifting.
5. **Archive** — Finalize and archive the completed change, leaving a clean audit trail.

## Stack

- [Vite](https://vitejs.dev/) — fast dev server and build tool
- [React](https://react.dev/) — UI library

## Audience

This repo is shared with demo attendees so they can follow along, review artifacts, and see how SDD structures AI-assisted development.
